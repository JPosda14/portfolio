Usa la skill sdd. A partir de `specs/$1/spec.md` y `specs/$1/plan.md` aprobados, escribe `specs/$1/tasks.md`.
Máximo ~10 tareas de 20–30 minutos, cada una con el RF que cubre y un «Hecho cuando:» verificable.
No escribas código ni edites fuera de `specs/`. Muestra las tareas y PARA.
